✈️ TravelEase — Travel Booking Website

A modern and responsive Travel Booking Website built as a 3-week Front-End Development Internship project.

TravelEase allows users to explore travel packages, search and filter destinations, view detailed package information, and book trips through a validated booking form.

🌍 Project Overview

The goal of this project was to build a complete real-world front-end web application using modern web development technologies.

The application provides an easy and user-friendly experience for discovering destinations and managing travel bookings.

✨ Main Pages
1. Home Page

The Home page introduces TravelEase and highlights popular travel packages, destinations, and key benefits.

2. Travel Packages

Users can browse all available travel packages.

The page includes:

Search
Category filtering
Price sorting
Package cards
View Details buttons
3. Package Details

Users can view complete information about a selected package, including:

Destination
Duration
Description
Price
Included services
Booking option
4. Booking Page

Users can book a selected travel package by providing:

Full name
Email
Phone number
Travel date
Number of travelers
Special requests

The form includes validation before submission.

5. My Bookings

Users can manage their saved bookings.

Available operations:

View bookings
Edit booking
Cancel booking

Bookings are stored using browser Local Storage.

💾 CRUD Functionality

The project implements CRUD functionality where applicable.

Operation	Implementation

🔎 Search & Filtering

The Travel Packages page provides:

Destination/package search
Category filtering
Price: Low to High

💾 Data Storage

Booking information is stored in the browser using:

▶️ How to Run the Project

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Navigate to the project folder:

cd travel-booking

Install dependencies:

npm install

Start the development server:

npm run dev

The application will run locally through the Vite development server.

🏗️ Production Build

To create a production build:

npm run build
